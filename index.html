Drat Repository for the neuroSCC Package

This is a custom drat repository hosting the neuroSCC package and its dependencies: ImageSCC, BPST, and Triangulation. These packages are not available on CRAN and are necessary for running SCC-based neuroimaging analyses as described in Wang et al. (2020).

Installation Instructions

To install neuroSCC and all its dependencies, run the following command in your R console:


install.packages("neuroSCC", dep = TRUE,
                 repos = c("https://iguanamarina.github.io/neuroSCC-drat",
                           "https://cloud.r-project.org"))

This will automatically configure your repositories and install neuroSCC along with the required packages from this drat repository.
